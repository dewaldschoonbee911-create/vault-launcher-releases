# Vault Launcher

One library for every PC game store, with achievements from every platform in one place, popups while you play, and community achievement sets for classic games that never had any.

**[Download the installer](https://github.com/dewaldschoonbee911-create/vault-launcher-releases/raw/main/latest/VaultLauncher-Setup-0.1.8.exe)** (version 0.1.8) and double-click it. After that, Vault Launcher updates itself.

- Steam, Epic, GOG, EA app, Ubisoft Connect, Battle.net and Xbox games in one library
- Steam, RetroAchievements and World of Warcraft achievements, with popups
- Retro consoles: point Vault at your ROM folders and play them through RetroArch with RetroAchievements (you supply your own game files)
- Free Classics: install and play classic games their owners made free (Beneath a Steel Sky, Lure of the Temptress, Flight of the Amazon Queen and more)
- Vault Sets (achievements for games that never had any): Command & Conquer, Red Alert, Tiberian Sun + Firestorm, Red Alert 2, Yuri's Revenge, Generals, Zero Hour, Renegade, Max Payne 2, StarCraft: Remastered

Vault Launcher does not include or download any games, ROMs or BIOS files. It only works with games already on your PC. Game names and artwork belong to their owners; this project is not affiliated with any of them.

This repository only holds the installers that power automatic updates.
